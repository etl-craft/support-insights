# Support Insights

Support Insights is the public data-movement example for
[etl-craft](https://github.com/etl-craft/etl-craft). It will demonstrate
MongoDB, Kafka and MinIO ingestion, warehouse transformations, business rules,
stewardship and failure recovery.

This initial commit preserves the generators and their UI, legacy SQL reference
sources, and the former package demo under [`project/`](project/). The S8 roadmap
builds the deployment, checks and full walkthrough here; they are not implemented
yet. No workflows or deployment are included in this seed commit.

The legacy SQL is reference only. Nothing runs it. For a runnable package example,
use etl-craft’s [Quick Start](https://github.com/etl-craft/etl-craft/blob/main/docs/quick-start.md).
